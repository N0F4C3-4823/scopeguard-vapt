# ScopeGuard UI design direction

The connected Taste MCP was not available in the tool catalog during the UI audit. The redesign therefore uses the existing product direction as a deliberate fallback: warm neutral surfaces, deep navy text, one restrained blue accent, compact status colors, generous whitespace, and progressive disclosure for technical detail.

## Principles

- One primary action per screen.
- Plain-language guidance first; scanner terminology belongs in expandable technical details.
- A stepper keeps new assessments sequential without hiding the ability to go back before execution.
- Status uses text, shape, and color together so it remains understandable without color perception.
- Live progress is derived from persisted work units. Indeterminate activity is used when a tool has no trustworthy percentage.
- Evidence previews expose the stored artifact and command provenance without changing the command/output-only PNG.
- Settings, dependency diagnostics, and Local AI remain available but are secondary to the assessment workflow.

## Tokens

- Background: warm neutral `#f6f7f9`
- Surface: white
- Text: deep navy `#17253a`
- Muted text: slate `#68778c`
- Accent: restrained blue `#2f6fed`
- Positive: green
- Attention: amber
- Failure/finding: red

Taste MCP was unavailable; this document records the fallback rather than implying that an external reference was consulted.
